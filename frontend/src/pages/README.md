# Frontend Pages Structure (ตรงตาม Requirement 5 หน้าหลัก + หน้า Admin ย่อย)

1. `Home/` - หน้าแรก แนะนำร้าน บริการเด่น จุดเด่น
2. `Services/` - หน้ารายการบริการซ่อม แบ่งตามหมวดหมู่ (Computer, Laptop, Phone) พร้อมปุ่มเลือกเพื่อไปแจ้งซ่อม
3. `AboutMe/` - หน้าเกี่ยวกับเรา พร้อมหัวข้อ Contact Us สำหรับกรอกฟอร์มแจ้งซ่อม
4. `Login/` - หน้าเข้าสู่ระบบสำหรับ Admin/ช่าง (เข้าผ่าน URL พิเศษ ไม่มีปุ่ม Login หน้าเว็บ)
5. `Admin/` - หน้าแดชบอร์ดและการจัดการหลังบ้าน
   - `Dashboard/` - สรุปรายรับ (สัปดาห์/เดือน), จำนวนลูกค้า, จำนวนช่าง, สินค้ารอซ่อม/ซ่อมแล้ว
   - `ServicesManagement/` - จัดการเพิ่ม/แก้ไข/ลบรายการบริการ
   - `Inbox/` - จัดการข้อความแจ้งซ่อม, เปลี่ยนสถานะซ่อม, เพิ่มความคิดเห็นช่าง
   - `UserManagement/` - จัดการเพิ่ม/แก้ไข/ลบผู้ใช้ และกำหนดสิทธิ์ (Admin / ช่าง)
